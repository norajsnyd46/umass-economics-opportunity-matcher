# UMass Economics Opportunity Matcher

A browser-based opportunity-matching quiz for UMass Amherst Economics and Resource Economics students.

## What it includes

- An 8-question questionnaire about interests, goals, experience, availability, compensation needs, barriers, and timing.
- Personalized recommendations across internships, research, campus organizations, volunteering/advocacy, and advising.
- An opportunity directory with links to official resources.
- A downloadable CSV copy of the opportunity database.
- Printable recommendation results.

## Privacy and limitations

Quiz answers are used in the current browser session and are not submitted to a server by this static site. Recommendations are starting points, not confirmations of eligibility or current openings. Students should verify deadlines, requirements, and availability on each opportunity's official page.

## Publish with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then select **Save**.
